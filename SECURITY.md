# Security Policy

## Supported Versions

This project supports the latest version of the JSON configuration published to the `main` branch. 

## Reporting a Vulnerability

If you discover a security vulnerability (e.g., prompt injection vulnerability, or inadvertent exposure of API endpoints/credentials within the logic), please do not report it through public GitHub issues.

Instead, please email the project maintainer directly or use GitHub's private vulnerability reporting feature if enabled. We will respond within 48 hours to acknowledge the report and outline a remediation plan.
